# Revisão de acesso ao Aura

Destino fornecido: https://typebot.co/consultor-demo

O endereço carrega o chatbot. A abertura observada apresenta Aura associada a outro produto e promete espera de até três segundos, conteúdo que não foi transportado para o portfólio.

O usuário informou que o fluxo coleta telefone. A inspeção do atendimento deve parar antes de inserir dados pessoais ou gerar encaminhamento real. Apenas observar o navegador não permite confirmar armazenamento, retenção, integrações ou quem recebe os dados.

Para oferecer uma demonstração segura para visitantes, recomendamos uma versão específica de portfólio que dispense telefone real e encerre a solicitação comercial como simulação. Remover referências a outros produtos, promessas não verificadas e qualquer aparência de parceria oficial. Não foram alterados o chatbot nem o site pessoal.

Nesta prévia o projeto é apresentado, mas o link externo não foi ativado. O usuário deve confirmar a revisão do fluxo ou fornecer uma versão apropriada antes da liberação. Esta avaliação é técnica e editorial, não uma auditoria jurídica.

## Decisão posterior do usuário
O usuário pediu link direto ao Typebot e remoção da seção intermediária. Implementado na prévia. Coleta externa não alterada. Publicação ainda pendente de aprovação.
