# Bíblico em Cores
Página estática de links para YouTube e TikTok, em uma coluna para celular, sem dependências externas ou rastreamento.

Abra index.html no navegador ou use a prévia local do VS Code. Links usam o identificador @biblicoemcores informado pelo usuário; destinos ainda precisam de conferência manual.

Endereço esperado após publicação do repositório: https://tinight.github.io/biblicoemcores/

A página principal do repositório foi preservada. Nenhuma publicação é confirmada apenas pela presença dos arquivos locais.
